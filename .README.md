# AI Career Copilot

> An AI-powered career assistant that helps software engineers discover relevant jobs, analyze job descriptions using Google Gemini, tailor resumes, generate cover letters, and track applications.

## 🚀 Overview

AI Career Copilot is a full-stack portfolio project built to streamline the job application process while showcasing modern AI engineering and full-stack development practices.

Instead of blindly applying to every job, the application helps identify the best opportunities based on your experience and generates tailored application materials.

---

## ✨ Planned Features

- 🔍 Job discovery
- 🤖 AI job matching with Gemini
- 📄 Resume tailoring
- ✉️ Cover letter generation
- 🎯 Interview preparation
- 📊 Application tracking
- 📈 Analytics dashboard
